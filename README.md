## 📖 About The Project

**Find The Crystals** is a first-person 3D exploration game developed in Unity. The game begins at a small base camp featuring a locked chest. To unlock it, the player must venture into the surrounding forest and gather 5 hidden crystals. Once all crystals are collected, the player is notified and can return to the base to unlock the chest.

This project was developed as a university semester assignment to demonstrate 3D game logic, custom player physics, and environment design.

## Features

* **Custom First-Person Controller:** Smooth movement system utilizing Unity's Player Input, featuring walking, jumping, and a fully functional ladder-climbing mechanic.
* **Procedural Crystal Generation:** The positions of the crystals are procedurally generated across the map each time the game starts, ensuring a unique exploration experience every playthrough.
* **Interactive Environment & UI:** Dynamic UI built with Canvas that tracks the player's collection progress in real-time and provides feedback when objectives are met.
* **Enclosed Level Design:** A detailed, immersive forest environment with natural boundaries to keep the player focused on the gameplay area.

## Controls

* **W, A, S, D / Arrow Keys** — Move
* **Mouse** — Look around
* **Space** — Jump
* **W / S** — Climb up/down (when interacting with a ladder)
* **Left Mouse Click** — Open the chest (requires 5 crystals)
* *Crystal collection is automatic upon walking over them.*

## Technologies Used

* **Game Engine:** Unity Engine
* **Language:** C#
* **Systems:** Player Input (Character Control), Unity Canvas (UI/UX), CharacterController (Physics)
